# raytracer-from-scratch

YouTube チャンネル「車輪の再発明ラボ」で、C++ を使ってレイトレーサーを一から作っている動画シリーズのコードです。
画面に光線を飛ばすところから始めて、金属やガラスが光を映す、写真のような 1 枚を描けるところまで進みます。

## 必要なもの
- Visual Studio Community（「C++によるデスクトップ開発」を入れたもの）

これだけで動きます。ほかのツールやライブラリは使いません。

## 動かし方
1. このページの緑色の「Code」ボタンを押し、「Download ZIP」を選びます。
2. ダウンロードした ZIP を右クリックし、「すべて展開」を選びます。
3. 見たい回のフォルダを開き、`.sln` ファイルをダブルクリックします。
4. Visual Studio が開いたら、F5 キーを押します。

## フォルダの見方
各回のフォルダは、2つずつあります。

- `epXX_start` … その回を始める時点のコードです。動画を見ながら、ここから一緒に書き進められます
- `epXX_done` … その回を終えた時点のコードです。うまく動かないときは、こちらと見比べてください

前の回で詰まってしまっても、次の回の `_start` から合流できます。

## 番外編の実験用プログラム
`extra/` フォルダには、番外編の動画で使った実験用プログラムが入っています。それぞれのフォルダが1つの Visual Studio プロジェクトです。`.sln` ファイルをダブルクリックして、F5 キーを押すと動きます。

`extra/random`（番外編「乱数の話」）は、画面に点を打って、乱数の「くせ」を目で見るプログラムです。1〜6 キーで乱数の作り方を切り替えます（1：`rand()`、2：掛けて、足して、余りを取る乱数、3：レイトレーサー編 #07 の xorshift、4：シードを 0 にした xorshift、5：シードを 1 に決めた xorshift で、何度押しても同じ絵になります、6：シードを起動した時刻にした xorshift で、押すたびに絵が変わります）。数の並びなどの確かめた結果は、コンソールの窓に出ます。Esc キーで終わります。キーの一覧は、`main.cpp` の先頭のコメントにあります。

`extra/gamma`（番外編「ガンマと sRGB」）は、画面に出す数字（0〜255）と、光の量のずれを、目で見て確かめるプログラムです。1〜6 キーで実験を切り替えます（1：白黒の細かい縞の横に、数字の 128 と 188 のグレーを並べる、2：黒から白へのグラデーションを、数字でまっすぐ並べたものと、光の量でまっすぐ並べたもので比べる、3：2 色を混ぜたグラデーションを、数字のまま混ぜたものと、光の量で混ぜたもので比べる、4：レイトレーサー編 #08 の絵で、ガンマ補正のあり・なしを比べる、5：32 段のグラデーションを、光の量が等しい間隔のものと、数字が等しい間隔のもので比べる、6：白黒の細かい絵を半分に縮めて、数字のまま平均したものと、光の量で平均したものを並べる）。P キーで今の実験の数字をコンソールの窓に出し、Esc キーで終わります。実験ごとのキー（W・H・C・G・B・R・S）と、キーの一覧は、`main.cpp` の先頭のコメントにあります。
